# T1
> 给定一个序列，每次可以把相邻两个和大于 $X$ 的数合并成 $Y$，求最多能进行多少次合并。
>
> $n \le 2 \times 10^5,1 \le X,Y \le 10^9$

想偏了，对着一个假的贪心调了两个小时，改成一个对的 DP 又调了一个小时/hec

分析一下性质，发现如果 $X>2Y$，那么两个合并的块不能继续合并，反之则可以继续合并。另外其实每个数只有初始状态和 $Y$ 两种可能性，从这个性质可以发现一个数被合并只有可能是三种情况：

- 两个初始的数合并
- 一个初始的数和一个 $Y$ 合并
- 两个 $Y$ 合并

而具体操作的时候，显然一个 $Y$ 能把它相邻的一个区间内 $\ge X - Y$ 的数全都合并进去。那么考虑从前往后 DP，那么需要关心的是前面有没有可以合并的以及有没有 $Y$。设 $f_i$ 表示前 $i$ 个的最后一段被合并成了 $Y$ 的最优情况，$g_i$ 表示前 $i$ 个的末尾有若干 $\ge X-Y$ 的数的最优方案，$ans_i$ 表示前 $i$ 个数的答案。但是这样的话 $g$ 还需要知道尾随了几个，因此直接把这些尾随的数全都扔进去，相当于钦定后面有一个要把他们加进去的方案数。然后分讨一下转移即可。

# T2
> 对于所有恰有 $n$ 个不同非空子序列的 01 字符串，输出字符串总数或这些字符串在按字典序从小到大排序后的第 $k$ 个。
>
> $1 \le n \le 10^9,-1 \le k \le 10^9$（$k=-1$ 为输出个数）

神了啊。被硬控还是太好玩了。

本质不同子序列是怎么数的来着？

考虑从后往前扫，设 $x,y$ 分别表示以 $0$ 和 $1$ 开头的子序列数量，初始都是 $0$，扫到 `1` 就 $y \leftarrow x + y + 1$，扫到 `0` 就 $x \leftarrow x + y + 1$。

但是这个式子不好看，于是令 $x \leftarrow x + 1$，$y \leftarrow y+1$，那么初始变成 $1$，每次相当于 $x \leftarrow x + y$ 或 $y \leftarrow x + y$，容易（在哪？）发现如果反过来就是辗转相减，而减到最后是 $1$ 要求最终的 $x, y$ 互质且 $x + y = n + 2$，因此计数只需要算 $\varphi(n+2)$。而每种 $x,y$ 显然在辗转相减的时候根据大小关系能够还原出来唯一的方案。

现在的问题是需要方案。考虑最终的 $x$ 越大，相当于有越多的以 `0` 开头的子序列，感性理解一下应该是比 $x$ 小的时候会更优，那么可以二分一下 $x \le t$ 且 $\gcd(x,n+2) = 1$ 的 $x$ 有几个，这可以类似 $\varphi$ 地计算，一次的复杂度是 $O(2^{w(n)})$ 的。

# T3
> 给定一个点权 $0/1$ 的二叉树，对于一个排列，每次可以交换两个相邻且对应二叉树上的 LCA 点权为 $1$ 的位置，求有多少等价类，对 $10^9+7$ 取模。
>
> $n \le 5000$

！？容斥？！

考虑二叉树的限制相当于是描述了某些数是无法交换的，因此如果存在一对相反的那么两个排列永远没法变成一个，反过来容易找到构造说明一定可以变成一个。

因此考虑相当于是对于不能交换的连无向边，那么本来是个无向图，然后给每条边定向成一个 DAG，每种定向方式对应了一种关系，那么最终的数量其实就是定向方案数。

考虑容斥。DAG 计数显然要找入度为 $0$ 的点，那么设 $F(S)$ 表示 $S$ 的导出子图的方案数，每次选出一个独立集 $T$ 表示入度为 $0$ 的点，那么向后面的所有入边都是确定的，剩下的就是 $F(S\setminus T)$。然而这样肯定会算重，直接容斥即可：

$$
F(S) = \sum_{\varnothing \neq T \subseteq S \And T \text{是独立集}}(-1)^{\left|T\right| - 1}F(S \setminus T)
$$

但是肯定不能直接子集枚举，考虑直接把转移路径暴力拆出来，会发现一条转移的路径相当于是把图划分成了若干个独立集，并且把路上的系数乘起来，那么设 $f_k$ 表示把图划分为 $k$ 个无序的非空独立集的方案数，再加上容斥系数并乘上 $k!$ 即可。也就是下面的式子：

$$
\operatorname{Ans} = \sum_{k=1}^n(-1)^{n-k}k!f_k
$$

那问题就是如何计算 $f$ 了。考虑树上 DP，设 $f_{u, k}$ 表示 $u$ 子树内的数划分为 $k$ 个独立集的方案数，那么分两种情况：

1. $v_u = 0$，此时两边的点都有连边，因此划分必须是把他俩分别合并，并且根节点单独一组。
2. $v_u = 1$，此时两边的点都没有连边，可以把两边的进行任意合并。考虑先左右合并，设子树合并的结果为 $C_k$，则 $f_{u,k} = C_{k - 1} + kC_k$，而 $C$ 的转移可以考虑 $C_{i+j-t} = L_iR_j\binom it \binom jt t!$，表示左右分别有 $i,j$ 组，选出 $t$ 组进行合并。这样时间复杂度就是 $O(n^3)$。$n^2$ 的做法看不懂啊，为什么我要搞明白镀铬都搞不明白的东西/ll
