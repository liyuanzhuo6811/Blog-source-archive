# T1

> 数轴上有 $n$ 个色块，编号 $1,2,\dots,n$。第 $i$ 个色块由正整数 $d_i$ 确定，三个顶点为 $(i,0)$、$(i,d_i)$、$(i+d_i,0)$，即覆盖区域 $\{(u,v) \mid i \le u \le i+d_i,\ 0 \le v \le i+d_i-u\}$。色块可以重叠，重叠部分只算一次面积。对每个 $x=1,2,\dots,n$，只保留编号 $x,x+1,\dots,n$ 的色块，求这些色块覆盖总面积的两倍（可以证明答案一定是整数），输出 $n$ 行，第 $i$ 行对应只保留 $i,i+1,\dots,n$ 时的答案。
>
> 数据范围：$1 \le n \le 3 \times 10^5$，$1 \le d_i \le 10^9$。

# T2

> 轨道是一条数轴，机器人最初位于坐标 $0$，没有携带试剂盒，可以沿数轴任意移动。轨道上有 $N$ 个检测点与 $N$ 个补给点，第 $i$ 个检测点位于坐标 $A_i$，第 $j$ 个补给点位于坐标 $B_j$，每个补给点存放一个通用试剂盒。机器人到达补给点时可以取走尚未取走的试剂盒，到达检测点时可以消耗一个已经取得的试剂盒完成该点的检测，每个检测点需要检测一次。检测点与补给点可以位于同一坐标，此时可以先取走试剂盒再完成检测；机器人携带的试剂盒数量没有额外限制，完成任务后不需要返回坐标 $0$。求完成全部检测所需的最小移动总距离。
>
> 数据范围：$1 \le N \le 10^5$，$1 \le A_i, B_i \le 10^9$，且 $A_i < A_{i+1}$、$B_i < B_{i+1}$（$1 \le i < N$），所有输入均为整数。

# T3

> 有 $n$ 条日志 $s_1,s_2,\dots,s_n$，每条都是只包含小写英文字母的非空字符串。为每条日志保留一个非空后缀（右端点与原字符串右端点相同的连续子串，也可以是整个字符串），再按日志原有顺序将这些后缀直接拼接成一份摘要。求所有选择方案中字典序最小的摘要。比较两个不同字符串时先比较第一个不同位置上的字符；若一个字符串是另一个的前缀，则较短的字典序更小。
>
> 数据范围：$1 \le T, n \le 2 \times 10^6$，每个 $s_i$ 只包含小写英文字母且 $1 \le |s_i| \le 2 \times 10^6$。记每组测试用例中所有字符串长度之和为 $L$，保证 $\sum L \le 2 \times 10^6$。

# T4

> 舞台上依次排列 $n$ 个灯光模块，第 $i$ 个模块的控制编码为 $a_i$。有 $q$ 条可选的调整指令，组成集合 $S$，每条指令由三个整数 $l,r,x$ 描述：对每个 $l \le i \le r$ 执行 $a_i \leftarrow a_i \oplus x$（$\oplus$ 表示按位异或）。每条指令按其编号区分，即使参数完全相同也算两条不同指令。一份预案对应一个指令子集 $U \subseteq S$，从最初的编码出发把 $U$ 中每条指令各执行一次，可以选择空集，且执行顺序不影响最终结果；记执行后第 $i$ 个模块的编码为 $a_i^{(U)}$。预案的分值为所有连续段分值之和，每段连续模块的分值为这段模块控制编码之和的平方，即 $K(U) = \sum_{1 \le i \le j \le n}\left(\sum_{k=i}^{j} a_k^{(U)}\right)^2$。求全部 $2^q$ 份预案的分值总和 $\sum_{U \subseteq S} K(U)$，答案对 $10^9+7$ 取模。
>
> 数据范围：$1 \le n \le 1000$，$0 \le q \le 10^5$，$0 \le a_i, x < 128$，$1 \le l \le r \le n$。
