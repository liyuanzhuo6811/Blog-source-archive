# T1

> 给定 $n$ 个非负整数 $a_0, a_1, \dots, a_{n-1}$ 首尾相接排成一个环。你可以进行任意多次操作：一次操作中选择一个下标 $i$，花费 $c_i$ 的代价，并把 $a_i, a_{(i+1) \bmod n}, \dots, a_{(i+k-1) \bmod n}$ 同时减去 $1$。要求求出把所有数都恰好变成 $0$ 所需的最小总代价。数据保证至少存在一种合法的操作方案。
>
> 数据范围：$1 \le k \le n \le 2 \times 10^5$，$0 \le a_i \le 10^9$，$1 \le c_i \le 10^4$，且保证存在至少一种操作方案能把所有数恰好变成 $0$。

# T2

> 给定一个长度为 $n$ 的小写英文字母串 $T$，需要回答 $q$ 次询问。每次询问给定两个整数 $m, k$，令 $S = T[1 \dots m]$，并考虑以下使用恰好 $k$ 个 $S$ 的过程：初始时令 $U = S$；接下来进行 $k-1$ 次操作，每次选择一个整数 $\ell$ 满足 $0 \le \ell < |S|$，且 $U$ 长度为 $\ell$ 的后缀等于 $S$ 长度为 $\ell$ 的前缀，随后在 $U$ 的末尾接上 $S[\ell+1 \dots |S|]$（当 $\ell = 0$ 时相当于直接在末尾接上一个完整的 $S$）。对于每次询问，请求出最终可能得到多少个本质不同的字符串 $U$（两个字符串本质不同当且仅当内容不同），答案对 $998244353$ 取模，各次询问互相独立。
>
> 数据范围：$1 \le n \le 10^6$，$1 \le q \le 10^5$，$T$ 仅包含小写英文字母，$1 \le m \le n$，$1 \le k \le 10^6$。

# T3

> 给定一个 $1$ 到 $n$ 的排列 $p_1, p_2, \dots, p_n$。对于当前排列，定义一个以 $1, 2, \dots, n$ 为顶点的有向无环图：对于每一对顶点 $x < y$，若 $\max(p_{x+1}, p_{x+2}, \dots, p_{y-1}) < \max(p_x, p_y)$，则存在一条从 $x$ 指向 $y$ 的有向边 $x \to y$（当 $y = x+1$ 时，空区间上的最大值视为 $0$，因此这条边总是存在）。一条从 $l$ 到 $r$ 的有向路径是一个顶点序列 $l = v_0 < v_1 < \dots < v_k = r$，且对每个 $1 \le t \le k$ 图中均存在有向边 $v_{t-1} \to v_t$。接下来有 $q$ 次操作，每次为以下两种之一：$1\ i\ j$ 表示交换 $p_i$ 和 $p_j$；$2\ i\ j$ 表示根据当前排列构造上述图，求从 $i$ 到 $j$ 的有向路径数量并对 $998244353$ 取模。本题测试数据随机生成，初始排列从所有排列中等概率随机选取，每次操作也从所有满足 $1 \le i < j \le n$ 的位置对 $(i, j)$ 中独立等概率随机选取。
>
> 数据范围：$2 \le n \le 2 \times 10^5$，$1 \le q \le 4 \times 10^5$，$p_1, p_2, \dots, p_n$ 是 $1$ 到 $n$ 的排列，$1 \le i < j \le n$，$t \in \{1, 2\}$，初始排列及每次操作均按题目所述方式随机生成。

# T4

> 有 $n$ 个任务，编号为 $1, 2, \dots, n$，任务之间的依赖关系形成一棵以任务 $1$ 为根的树：对于每个 $2 \le v \le n$，任务 $v$ 的父任务为 $p_v$，且任务 $v$ 必须在任务 $p_v$ 完成后才能开始。你需要把所有任务排成一个执行顺序 $a_1, a_2, \dots, a_n$，使每个任务恰好出现一次且所有依赖均得到满足。若执行顺序中的一个连续片段 $a_l, a_{l+1}, \dots, a_r$ 满足 $p_{a_{i+1}} = a_i\ (l \le i < r)$，则称这个连续片段为一段连续接力，其长度为 $r - l + 1$。给定正整数 $K$，要求执行顺序中不存在长度大于 $K$ 的连续接力，求合法执行顺序的数量，答案对 $998244353$ 取模。
>
> 数据范围：$2 \le n \le 4000$，$2 \le K \le n$，$1 \le p_v < v$。
