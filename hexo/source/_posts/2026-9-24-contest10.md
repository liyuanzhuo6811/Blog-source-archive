# T1

> 有 $n$ 个位置，需要向其中分别填入 $1,2,\dots,n$，每个数恰好使用一次，设填出的排列为 $p_1,p_2,\dots,p_n$。你收到 $m$ 条记录，第 $i$ 条记录包含一个整数 $c_i$ 和一个非空位置集合 $S_i$，要求 $\max_{x \in S_i} p_x = c_i$（输入时每行先给出集合大小 $k_i$，再给出 $c_i$，最后给出 $k_i$ 个互不相同的下标）。求同时满足所有记录的排列数量，答案对 $998244353$ 取模；若不存在这样的排列则输出 $0$。不同记录可以完全相同，不同记录对应的集合之间也可以有公共位置，特别地 $m=0$ 时没有任何限制。
>
> 数据范围：$1 \le T \le 10^4$，$1 \le n \le 10^6$，$0 \le m \le 10^6$，$1 \le k_i,c_i \le n$，$1 \le s_{i,j} \le n$，同一集合内的下标互不相同。记 $N=\sum n$、$M=\sum m$、$K=\sum k_i$（三个求和均覆盖同一输入文件中的所有数据组），则 $N,M,K \le 10^6$。

# T2

> 有一棵包含 $n$ 个顶点的树，顶点编号为 $1 \sim n$，每条边上都有一扇最初关闭的门。每扇门恰好有一把钥匙，所有钥匙被分为 $m$ 个非空钥匙环，编号为 $1 \sim m$，边上的整数 $c$ 表示它的钥匙属于第 $c$ 个钥匙环。你从某个顶点出发，一开始就携带全部钥匙环，可以进行以下操作：沿已经打开的门向任意方向移动，次数不限；位于一扇关闭的门的任意一个端点时，使用其钥匙将门打开（打开的门不会再次关闭）。钥匙环的使用顺序可以任意选择，但一旦使用某个钥匙环打开了一扇门，就必须先打开这个钥匙环对应的全部门，才能使用其他钥匙环，同一个钥匙环内部各把钥匙的顺序不限。对每一个顶点，判断从该顶点出发能否最终打开所有门，输出一行长度为 $n$ 的字符串，第 $i$ 个字符为 $1$ 表示从顶点 $i$ 出发可行，为 $0$ 表示不可行。
>
> 数据范围：$1 \le T \le 10^4$，$2 \le n \le 10^6$，$1 \le m < n$，$1 \le u,v \le n$，$u \ne v$，$1 \le c \le m$。保证输入的边构成一棵树，并且每个钥匙环至少出现一次。设 $N$ 为一个输入文件中所有数据组的 $n$ 之和，则 $N \le 10^6$。

# T3

> 对于一个由正整数组成的数组 $b=(b_1,b_2,\dots,b_m)$，定义它的权值为不能表示成其元素子集和的最小正整数，即 $F(b)=\min\{x \in \mathbb{Z}_{>0} \mid \text{不存在 } S \subseteq \{1,2,\dots,m\} \text{ 使得 } x=\sum_{i \in S} b_i\}$。这里选择的是下标集合：每个位置的元素至多选择一次，不同位置的元素即使数值相同也可以分别选择，所选位置不要求连续，允许选择空集（其元素之和为 $0$）。给定一个长度为 $n$ 的正整数数组 $a=(a_1,a_2,\dots,a_n)$，求所有非空连续子数组的权值之和 $\sum_{l=1}^{n}\sum_{r=l}^{n}F((a_l,a_{l+1},\dots,a_r))$，答案对 $998244353$ 取模。
>
> 数据范围：$1 \le n \le 5 \times 10^5$，$1 \le a_i \le 10^{18}$。

# T4

> 给定一个长度为 $n$ 的排列 $p_1,p_2,\dots,p_n$，其中 $1 \sim n$ 的每个整数恰好出现一次。对于一个数组 $a_1,a_2,\dots,a_s$，如果可以将它的全部下标划分为若干组，使得每组的下标按从小到大排列后为 $i_1<i_2<\dots<i_q$，并满足 $q \ge 2$ 且 $a_{i_1}<a_{i_2}<\dots<a_{i_q}$，则称这个数组可以合法分组。每个下标必须恰好属于一组，组内下标不必连续，规定空数组可以合法分组。你可以删除排列中的若干个元素，剩余元素的数值和相对顺序不变，不需要重新编号。请计算至少删除多少个元素，才能让剩余数组无法合法分组；如果原排列已经无法合法分组，答案为 $0$。
>
> 数据范围：$1 \le T \le 100$，$1 \le n \le 5000$，$p$ 是 $1 \sim n$ 的排列。设 $N$ 为一个输入文件中所有数据组的 $n$ 之和，则 $N \le 5000$。
