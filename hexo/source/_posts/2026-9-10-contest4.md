# T1

> 给定 $n$ 个数 $a_1,a_2,\dots,a_n$。记 $\varphi(n)$ 表示 $1$ 到 $n$ 中与 $n$ 互质的数字个数。求 $\sum_{i=1}^{n}\sum_{j=i}^{n}\varphi(a_i+a_j)$。
>
> 数据范围：$1 \le n \le 5000$，$1 \le a_i \le 10^9$。

# T2

> 平面上有 $n$ 条线段，其中第 $i$ 条线段连接 $(0,a_i)$ 与 $(T,b_i)$ 两个点，保证每条线段与至多 $K$ 条其他线段相交。有 $q$ 次询问，每次询问给出一个点 $(c,d)$；考虑直线 $x=c$ 与这 $n$ 条线段的交点 $(c,y_1),(c,y_2),\dots,(c,y_n)$，求 $\min |y_i-d|$。输出的答案需要以最简分数 $p/q$ 的形式给出，其中 $p \ge 0$、$q > 0$。
>
> 数据范围：$1 \le n \le 10^6$，$1 \le q \le 10^4$；$1 \le T \le 10^9$，$0 \le K \le 1000$；$0 \le a_i,b_i,d \le 10^9$；$0 \le c \le T$；$a_i$ 两两不同，$b_i$ 两两不同，且保证每条线段至多与 $K$ 条其他线段相交。

# T3

> 给定实数轴上的 $n$ 个闭区间，每个区间的两个端点都是 $1$ 到 $n$ 之间的整数。将这些区间按某个顺序排列，得到一个排列 $p_1,p_2,\dots,p_n$。如果对任意 $1 \le k \le n$，区间 $p_1,p_2,\dots,p_k$ 的并集都是连通的（等价地说，该并集是实数轴上的一个闭区间），则称该排列是好的。求好的排列的数量，对 $998244353$ 取模后输出。
>
> 数据范围：$1 \le n \le 6000$，$1 \le l_i \le r_i \le n$。

# T4

> 给定一个排列 $p_1,p_2,\dots,p_n$，要给每个数标上一个号 $b_i$，其中 $b_i \in \{0,1,2\}$。一个标号方案合法，当且仅当对于每个长度至少为 $2$ 的子区间，其最大值和次大值的标号都不同。一个标号方案的分数为所有长度至少为 $3$ 且前三大值的标号都不同的子区间个数。问合法标号方案最大的分数是多少。
>
> 数据范围：$3 \le n \le 5 \times 10^5$，$1 \le p_i \le n$，保证 $p_i$ 两两不同。
