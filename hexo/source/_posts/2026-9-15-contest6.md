# T1

> 给定一个长度为 $n$ 的字符串 $s$，只含小写英文字母。你必须先选择一个非空连续区间 $[l,r]$（允许 $l=r$），把这段字符的顺序翻转；翻转之后可以进行任意多次消除操作：每次选择两张相邻且字母相同的卡片将它们一起删除，剩下的卡片按原顺序靠拢。要求判断是否存在一种翻转方式，使得翻转后能把所有卡片全部消除；若存在，还要输出任意一对满足 $1 \le l \le r \le n$ 的 $l,r$。本题有多组测试数据，无解输出 `NO`，有解输出 `YES` 与 $l,r$（答案不唯一，使用自定义校验器）。
>
> 数据范围：$1 \le T \le 10^4$，$1 \le n \le 10^6$，保证单个测试点内 $\sum n \le 10^6$，$s$ 仅含小写英文字母。

# T2

> 有 $n$ 名队员，编号 $1$ 至 $n$，第 $i$ 名队员的优先级为 $p_i$，其中 $p_1,p_2,\dots,p_n$ 是 $1$ 到 $n$ 的一个排列，优先级数值越小越优先。另有 $n-1$ 个互不相同的任务，每个任务指定两名候选队员，只能由其中一人领取；把队员看作顶点、任务看作连接其两名候选队员的无向边，这些关系构成一棵树。每名队员至多领取一个任务且初始都未领取。你需要选择一种顺序把全部任务依次发布，发布一个任务时：若两名候选队员都未领取任务，则由优先级数值较小者领取；若恰有一人未领取任务，则由这名队员领取；若两人都已领取任务，则该任务失败。求使所有任务都成功的发布顺序数量（两个顺序不同当且仅当某个发布位置上的任务不同），答案对 $998244353$ 取模。特别地，$n=1$ 时没有任务，空顺序视为一种成功顺序。
>
> 数据范围：$1 \le n \le 2 \times 10^5$，$p$ 是 $1$ 到 $n$ 的排列，$1 \le u,v \le n$，输入的 $n-1$ 条边构成一棵树。

# T3

> 给定一棵有 $n$ 个顶点的树，顶点编号为 $1$ 至 $n$，最初所有顶点都没有颜色。你需要选择一个 $1$ 到 $n$ 的排列，并按该排列的顺序依次为每个顶点染色：处理顶点 $u$ 时，令 $S$ 为与 $u$ 相邻且已经染色的顶点的颜色集合，把 $u$ 的颜色设为 $\operatorname{mex}(S)$，其中 $\operatorname{mex}(S)$ 表示没有出现在 $S$ 中的最小非负整数（如 $\operatorname{mex}(\varnothing)=0$，$\operatorname{mex}(\{0,2\})=1$）。染色完成后按顶点编号得到颜色数组 $(c_1,c_2,\dots,c_n)$。求所有排列能够得到的不同颜色数组的数量，答案对 $998244353$ 取模；不同排列若得到相同的颜色数组只计算一次，且顶点编号固定，不因树的对称性把两个不同数组视为相同。
>
> 数据范围：$1 \le n \le 2 \times 10^5$，$1 \le u,v \le n$，输入的边构成一棵树。

# T4

> 给定一个长度为 $n$ 的整数序列 $a_1,a_2,\dots,a_n$。一个长度至少为 $2$ 的连续子区间 $[l,r]$ 被称为合格区间，当且仅当存在整数 $m$ 满足 $l \le m < r$，使得 $a_l,\dots,a_m$ 中出现过的数字集合与 $a_{m+1},\dots,a_r$ 中出现过的数字集合完全相同（每种数字在两段中的出现次数可以不同）。请求出合格区间的数量；同一个区间即使存在多个合法切分位置也只计算一次，答案不取模。
>
> 数据范围：$1 \le n \le 10^6$，$1 \le a_i \le n$。
