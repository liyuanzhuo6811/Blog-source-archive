# T1

> 给定一个长度为 $n$ 的排列 $p_1,p_2,\dots,p_n$。若 $1 \le i<j \le n$ 且 $p_i>p_j$，则称 $(i,j)$ 是一对错序记录。至多可以选出 $1 \le l \le r \le n$，把区间 $p_l,p_{l+1},\dots,p_r$ 的顺序完全反转一次（区间外的记录不变）。求操作后错序记录数量的最大值。
>
> 数据范围：$1 \le T \le 10^5$，$1 \le n \le 8000$，$1 \le p_i \le n$，$p$ 为排列且 $\sum n \le 8000$。

# T2

> 给定一个长度为 $n$ 且单调不减的正整数序列 $a_1 \le a_2 \le \dots \le a_n$。可以进行任意次（包括零次）操作，每次操作先读取当前值 $x=a_i$（要求 $1 \le x \le n$），再执行 $a_x \leftarrow a_x+1$，其中下标 $x$ 按该次操作开始时的值确定。判断是否存在合法方案使数列最终成为 $1,2,\dots,n$ 的排列；若存在，还需输出任意一种方案：操作次数 $K$ 与依次选择的下标 $p_1,p_2,\dots,p_K$，否则输出 NO。
>
> 数据范围：$1 \le T \le 1000$，$1 \le n \le 1000$，$1 \le a_i \le 2000$，$a_1 \le a_2 \le \dots \le a_n$，$\sum n \le 1000$。

# T3

> 给定一棵 $n$ 个点的树，第 $i$ 个点有稳定亮度 $m_i$ 与共振亮度 $w_i$，外部中央调谐器接入编号为 $k$ 的结点。每次启动给出直接作用半径 $L$，每个点必须从三种互斥模式中选择一种：恒稳模式，亮度为 $m_i$；强共振模式，亮度为 $w_i$，该模式合法当且仅当它至少有一个相邻点进入稳相核模式，或者它到接入点 $k$ 的树上距离不超过 $L$；稳相核模式，亮度为 $0$，一个稳相核可以同时支持它的所有相邻点进入强共振模式，且没有容量限制。每次启动独立地重新选择全部点的模式，求该次启动中总亮度的最大值。共 $q$ 次启动，每次给出一个 $L_i$，分别输出答案。
>
> 数据范围：$1 \le n,q \le 10^5$，$0 \le L_i \le 10^5$，$1 \le m_i,w_i \le 10^9$，$1 \le k,u,v \le n$。

# T4

> 有一块 $R$ 行 $C$ 列的显示屏，初始恰有 $N$ 个互不相同的像素 $(S_i,E_i)$ 已点亮，且至少还有一个像素未点亮。每一轮选择一个方向（上、下、左、右）向整块显示屏发送同一条复制指令：在本轮开始时已经点亮的每个像素，会使该方向上与它相邻的像素在下一轮开始时点亮，若相邻位置在显示屏之外则该次复制无效；已经点亮的像素保持点亮，本轮新点亮的像素不能在同一轮内继续复制。可以自行选择每一轮的方向，求使全部像素都点亮所需的最少轮数。
>
> 数据范围：$1 \le N \le 300$，$1 \le R,C \le 10^9$，$1 \le S_i \le R$，$1 \le E_i \le C$，各 $(S_i,E_i)$ 互不相同，且 $N<R \times C$。
