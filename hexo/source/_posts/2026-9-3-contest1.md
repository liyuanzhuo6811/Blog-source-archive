# T1

> 给定两个整数 $n, k$ 和一个严格递增的整数序列 $r_1, r_2, \dots, r_k$，其中 $n = r_k$。
>
> 该序列把位置 $1, 2, \dots, n$ 划分成 $k$ 个连续的区间 $[1, r_1], [r_1 + 1, r_2], \dots, [r_{k-1} + 1, r_k]$（规定 $r_0 = 0$）。
>
> 对于每个由 $1, 2, \dots, n$ 构成的排列 $p$，定义 $F(p) = \prod_{i=1}^{k} \min_{r_{i-1} < j \le r_i} p_j$。
>
> 求所有排列 $p$ 的 $F(p)$ 之和对 $998244353$ 取模的结果。
>
> $1 \le k \le n \le 100$。

# T2

> 给定一张有 $n$ 个点、$m$ 条边的连通无向图，所有边按输入顺序编号为 $1 \sim m$。点之间可能有多条边，但不存在自环。
>
> 若一条从点 $1$ 到点 $v$ 的路径边权和在所有这样的路径中最小，则称它是一条最短路。把一条最短路从点 $1$ 到终点依次经过的边编号写成一个序列，两条终点相同的最短路按该序列字典序比较。
>
> 对每个点 $v$，求出字典序第二小的最短路：若存在，输出这条路径上所有边的编号之和。若不存在，输出 $-1$。点 $1$ 的答案始终为 $-1$。
>
> $2 \le n \le 2 \times 10^5$，$n - 1 \le m \le 5 \times 10^5$，$1 \le w_i \le 10^9$。

# T3

> 有 $n$ 个点，第 $i$ 个点有坐标 $x_i$ 和颜色 $c_i$。要求选出其中 $m$ 个点，且选出的点颜色两两不同。
>
> 设选出的点的坐标为 $y_1, y_2, \dots, y_m$，定义权值为 $\sum_{1 \le i < j \le m} (y_i - y_j)^2$。求所有合法选择方案中最小的权值。注意答案可能超过 $2^{63} - 1$。
>
> $1 \le m \le n \le 5 \times 10^5$，$1 \le x_i \le 10^9$，$1 \le c_i \le n$，且 $c$ 中至少有 $m$ 个不同的值。

# T4

> Alice 和 Bob 在玩游戏。现在有一个数组 $a_1, a_2, \dots, a_n$ 和一个数字 $X$，两个人轮流行动，Alice 先手，游戏一共会进行 $k$ 轮。
>
> 每轮行动，玩家可以选择数组中的一个子区间 $[l, r]$（$1 \le l \le r \le n$），然后把 $a_i\ (l \le i \le r)$ 变成 $X - a_i$。Alice 想最大化 $\sum_{i=1}^{n} a_i$，Bob 想要最小化。
>
> 问两个人都按最优策略，最后数组中所有元素的和是多少。
>
> $1 \le n \le 2 \times 10^5$，$2 \le X \le 10^9$，$1 \le k \le 10^9$，$0 \le a_i \le X$。
