# T1

> 有 $N$ 个温控舱，编号 $1$ 到 $N$，第 $i$ 个温控舱的当前温度为整数 $a_i$ 摄氏度，温度可以为负数，不同温控舱的温度可以相同。一次调节选定一个温控舱，并执行以下两种操作之一：若它的温度不是当前所有温控舱中的最高温度，则把它的温度升高 $1$，即 $a_i \leftarrow a_i + 1$；若它的温度不是当前所有温控舱中的最低温度，则把它的温度降低 $1$，即 $a_i \leftarrow a_i - 1$。每次调节之前都会依据当前温度重新判断最高温度与最低温度，若多个温控舱同时达到最高温度或最低温度，则它们都不能继续向对应的方向调节。给定初始温度序列 $A = (a_1, a_2, \dots, a_N)$ 与目标温度序列 $B = (b_1, b_2, \dots, b_N)$，判断能否把温度调整为 $B$；若能，求出最少需要的调节次数，否则输出 $-1$。
>
> 数据范围：$1 \le T \le 10^4$，$1 \le N \le 4 \times 10^5$，$-10^9 \le a_i, b_i \le 10^9$，且 $\sum N \le 2 \times 10^6$。

# T2

> 有 $n$ 次按时间先后编号为 $1$ 到 $n$ 的采样，第 $i$ 次采样的频率为整数 $a_i$。需要截取一个连续观测窗口 $[l, r]$（$1 \le l \le r \le n$）并选择一个整数频率 $v$ 启用滤波，滤波会去掉窗口内所有频率等于 $v$ 的采样，其余采样保持原时间顺序。称该窗口合法，当且仅当存在整数 $v$ 同时满足：频率 $v$ 在完整的 $n$ 次采样中至少出现过一次；窗口的两个端点都不会被滤去，即 $v \ne a_l$ 且 $v \ne a_r$；滤波后窗口内保留的频率序列 $c_1, c_2, \dots, c_k$ 严格递增，即 $k = 1$，或对所有 $1 \le i < k$ 有 $c_i < c_{i+1}$。注意 $v$ 可以只出现在窗口外，此时窗口内没有采样被滤去；窗口长度按滤波前计算，为 $r - l + 1$。求合法观测窗口的最大长度，若不存在合法窗口则输出 $0$。
>
> 数据范围：$1 \le T \le 1000$，$1 \le n \le 2 \times 10^6$，$1 \le a_i \le n$，且 $\sum n \le 2 \times 10^6$。

# T3

> 有一棵包含 $n$ 个终端、编号 $1$ 到 $n$ 的树，终端之间由 $n - 1$ 条无向线路连接且相互连通。信号共有 $m$ 种类型，编号 $1$ 到 $m$，终端 $i$ 当前保存 $k_i$ 种不同类型的信号（可以一种都不保存）。选择一个终端作为控制中心，除控制中心外只与一条线路相连的终端称为末端，从控制中心到某个末端的唯一简单路径称为一条传输路径，该路径的信号集合是路径上所有终端（含控制中心与末端）保存的信号类型的并集。一次调试可以选定一个末端，把它保存的信号类型集合改成 $m$ 种类型的任意子集（包括空集），其他终端不受影响；特别地，控制中心即使只与一条线路相连也不属于末端，不能被调试。要求所有传输路径的信号集合完全相同。请分别对以终端 $1, 2, \dots, n$ 为控制中心的情况，求出最少需要的调试次数，各次计算相互独立，都从输入的初始状态出发。
>
> 数据范围：$2 \le n \le 2 \times 10^5$，$1 \le m \le 6$，$0 \le k_i \le m$，$1 \le t_{i,j} \le m$，同一个终端保存的信号类型互不相同，$1 \le u_i, v_i \le n$，$u_i \ne v_i$。

# T4

> 有 $n$ 个状态，编号 $1$ 到 $n$。系统每轮按照一张预先确定且始终不变的轮换表更新状态，需要选择一个函数 $f : \{1, 2, \dots, n\} \to \{1, 2, \dots, n\}$，当系统当前处于状态 $x$ 时，一轮更新后进入状态 $f(x)$，每一轮都使用同一个 $f$。函数 $f$ 必须满足：对任意 $1 \le x \le n$，都有 $f(x) \ne x$；连续更新 $k$ 轮后，任意初始状态 $x$ 都回到自身，即 $f^k(x) = x$（$f^k$ 表示把 $f$ 连续复合 $k$ 次，只要求第 $k$ 轮后回到初始状态，不要求 $k$ 是最小正周期）。给定多组相互独立的 $n$ 与 $k$，分别判断是否存在满足条件的函数 $f$。
>
> 数据范围：$1 \le t \le 10^4$，$1 \le n \le 10^{18}$，$1 \le k \le 10^{15}$，且单个输入文件中不同的 $k$ 值不超过 $50$ 个。
