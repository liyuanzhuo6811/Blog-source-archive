# T1

> 给定一个长度为 $n$ 的 01 串 $S$，定义 $f(S)$ 为把 $S$ 当作二进制数时的值（$S$ 可以有前导 $0$）。要求选出两个非空子串 $S_1, S_2$（两者可以重叠），使得 $f(S_1) \oplus f(S_2)$ 最大，并输出这个最大值。输出时以二进制形式给出，且不能有前导 $0$。输入含多组测试用例，每组给出 $n$ 与串 $S$。
>
> 数据范围：$1 \le T \le 100$，$2 \le n \le 10^7$，所有测试数据中 $n$ 的总和（记作 $s$）不超过 $10^7$。

# T2

> 有 $N$ 座城市，编号 $0$ 到 $N-1$，一条环形铁路连接所有城市，城市 $i$ 与城市 $(i+1) \bmod N$ 之间的双向通行时间为 $L_i$。你可以修建任意数量的新铁路，每条新铁路连接任意两座城市且双向通行时间可设为任意非负实数；随后从 $N$ 座城市中选一座作为首都。政策确定后，城市 $i$ 的欠发达指数 $d_i$ 为从首都出发利用所有现有铁路与新建铁路到达城市 $i$ 的最短时间。共有 $M$ 位居民搬家，第 $j$ 位居民从城市 $X_j$ 搬到城市 $Y_j$，声望定义为 $\sum_{j=1}^{M} (d_{X_j} - d_{Y_j})$。你需要自由决定新建铁路及其通行时间并选择首都，使声望最大。此外环形铁路还会进行 $Q$ 次修改，第 $k$ 次修改把城市 $T_k$ 与城市 $(T_k+1) \bmod N$ 之间的通行时间改为 $Z_k$，修改永久保留。请输出最开始以及每次修改后，重新制定政策所能获得的最大声望。
>
> 数据范围：$3 \le N \le 5 \times 10^5$，$1 \le M, Q \le 5 \times 10^5$，$0 \le L_i, Z_k \le 10^6$，$0 \le X_j, Y_j, T_k < N$，$X_j \ne Y_j$，输入中的所有数均为整数。

# T3

> 小 R 摆好了一排共 $n$ 个布丁，每个布丁用 $0$ 或 $1$ 表示口味，因此这排布丁可看作长度为 $n$ 的 01 串。初始状态为 $X$，目标状态为 $Y$。一次操作中，选择整数 $l, r$ 满足 $1 \le l < r \le n$，且当前 01 串中下标 $l$ 到 $r$ 的子串是回文串，然后把该区间内所有口味翻转（$0$ 变 $1$，$1$ 变 $0$）。要求构造一组操作把 $X$ 变成 $Y$，使用的操作次数越少得分越高。输出时先给出操作次数 $m$，再按执行顺序输出 $m$ 行，每行两个整数 $l, r$ 表示一次操作；执行该操作前当前串的 $[l, r]$ 必须是长度至少为 $2$ 的回文串。多组测试用例的答案按输入顺序连续输出。
>
> 数据范围：$1 \le T \le 500$，$4 \le n \le 1000$，$X, Y$ 均为长度为 $n$ 的 01 串。

# T4

> 有一个 $n \times n$ 的矩阵 $A$，行从上到下、列从左到右均以 $1$ 到 $n$ 编号，初始时 $A_{i,j} = (i-1)n + j$。定义两种操作：$\mathrm{Row}(r)$ 将第 $r$ 行循环右移一格，即原来位于 $(r,j)$（$1 \le j < n$）的元素移动到 $(r,j+1)$，原来位于 $(r,n)$ 的元素移动到 $(r,1)$；$\mathrm{Col}(c)$ 将第 $c$ 列循环下移一格，即原来位于 $(i,c)$（$1 \le i < n$）的元素移动到 $(i+1,c)$，原来位于 $(n,c)$ 的元素移动到 $(1,c)$。给定长度为 $n$ 的序列 $P_1, P_2, \dots, P_n$，一轮操作依次执行 $\mathrm{Row}(1), \mathrm{Col}(P_1), \mathrm{Row}(2), \mathrm{Col}(P_2), \dots, \mathrm{Row}(n), \mathrm{Col}(P_n)$，每个操作都在上一个操作所得的矩阵上进行。求最小的正整数 $k$，使得连续执行 $k$ 轮操作后矩阵中每个元素都回到初始位置；由于答案可能很大，输出 $k$ 对 $998244353$ 取模后的结果。
>
> 数据范围：$1 \le n \le 2 \times 10^5$，$1 \le P_i \le n$，输入中的所有数均为整数。
