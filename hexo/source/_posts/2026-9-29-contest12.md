# T1

> Lynette_lovely 和 teylnol_evteyl 经营一家餐馆。一晚，Lynette_lovely 准备了 $n$ 份相同的食材，她会依次做出 $m$ 道菜，每道菜需消耗非负整数份食材（即允许某些菜消耗 $0$ 份食材），完成这 $m$ 道菜之后食材需全部用完。当晚依次来了 $k_0+k_1$ 名客人，teylnol_evteyl 会依次给这些客人上菜，要求：按照菜的制作顺序依次上菜；每道菜恰好分给一名客人，并且这些菜对应的客人编号单调不降；允许某些客人一道菜也分不到。对于前 $k_0$ 名客人，每名客人吃到菜的食材总份数为偶数；对于后 $k_1$ 名客人，每名客人吃到菜的食材总份数为奇数。求一共有多少种做菜和上菜的方案，对 $998244353$ 取模。两种方案不同，当且仅当存在某个 $i$，第 $i$ 道菜消耗的食材份数不同，或被分给的客人不同。
>
> 数据范围：$0 \le n,m,k_0,k_1 \le 10^7$，$1 \le m$，$k_1 \le m$，$k_1 \le n$，$1 \le k_0+k_1$，且 $2 \mid (n-k_1)$。

# T2

> 构造一个序列 $a$，下标从 $0$ 开始，初始长度为 $1$，并且 $a_0=0$。定义运算 $x \circ y = (x \operatorname{xor} y)+1$，其中 $\operatorname{xor}$ 指按位异或运算。每次操作给定非负整数 $i,j$，需要保证 $i,j$ 小于当前序列长度，然后将 $a_i \circ a_j$ 加入序列末尾；操作次数不能超过 $120$ 次。给定整数 $n$，要求经过这些操作后，最终序列的最后一个元素是 $n$，且其中所有元素都小于等于 $n$。可以证明 $[0,2^{30})$ 内的所有 $n$ 都存在满足条件的操作序列，你需要输出一组方案：第一行是操作次数 $m$，接下来 $m$ 行每行两个整数 $i,j$ 描述一次操作。
>
> 数据范围：$1 \le T \le 10^4$，$1 \le n < 2^{30}$。

# T3

> teylnol_evteyl 的游戏里共有 $n$ 个角色，第 $i$ 名角色的等级是一个不超过 $m$ 的非负整数 $x_i$。Lynette_lovely 根据 teylnol_evteyl 的信息总结出一个 $n \times n$ 的整数矩阵 $A$ 和一个长度为 $n$ 的整数序列 $b$，满足：$A_{i,i}=-1$，$A_{i,j}=A_{j,i}$，$0 \le b_i \le m$，$0 \le x_i \le b_i$；对于 $i<j$，若 $A_{i,j} \ne -1$，则 $x_i+x_j=A_{i,j}$。注意，$A$ 和 $b$ 只记录直接给出的限制，不要求包含能够由这些限制进一步推导出的信息。请你计算有多少组 $(A,b)$，使得存在序列 $x_i$ 满足上面的条件，答案对 $998244353$ 取模。
>
> 数据范围：$1 \le n \le 5 \times 10^3$，$0 \le m < 998244353$。

# T4

> 有一个 $n \times n$ 的矩阵 $a$，初始全为 $1$。接下来进行了 $n$ 次操作，每次选择一个子矩阵和一个正整数 $v$，将子矩阵中的 $a_{x,y}$ 全部乘上 $v$：第 $i$ 次操作给出 $u,d,l,r,v$，表示把所有满足 $u \le x \le d,\ l \le y \le r$ 的 $a_{x,y}$ 乘上 $v$。随后又选取了 $n$ 个子矩阵计算每个子矩阵中数之和并对给定正整数 $M$ 取模：第 $i$ 次询问给出 $U,D,L,R$，求所有满足 $U \le x \le D,\ L \le y \le R$ 的 $a_{x,y}$ 之和对 $M$ 取模的结果。请依次输出这 $n$ 次询问的答案。
>
> 数据范围：$1 \le n \le 3 \times 10^5$，$2 \le M \le 998244353$，$1 \le v \le 998244352$，$1 \le u \le d \le n$，$1 \le l \le r \le n$，$1 \le U \le D \le n$，$1 \le L \le R \le n$。
