# T1

> 给定 $n$ 个小写字母串 $s_1, s_2, \dots, s_n$。对于 $1 \le j \le i \le n$，定义 $f_{i,j}$ 为从 $s_1, s_2, \dots, s_i$ 中选出恰好 $j$ 个串时，这 $j$ 个串的最长公共前缀长度的最大值；特别地，只选一个串时它的公共前缀长度就是该串长度本身。需要对每个 $i = 1, 2, \dots, n$ 求出 $\sum_{j=1}^{i} (f_{i,j} \oplus j)$，并按 $i$ 从小到大逐行输出。
>
> 数据范围：$1 \le n \le 5 \times 10^5$，$\sum_{i=1}^{n} |s_i| \le 10^6$，字符串只包含小写字母。

# T2

> 有一个长度为 $n$ 的序列，每个位置上放有若干个棋子，每个棋子是红色、黄色或蓝色之一。保证每个位置至少有一个棋子，并且同一个位置上棋子的颜色两两不同。现在要把序列划分成若干个连续段，一个段是好的当且仅当这个段内所有位置的红棋总数不小于黄棋总数，并且不小于蓝棋总数。求划分之后，所有好的段的总长度最大是多少。
>
> 输入给出 $n$ 和一个长度为 $n$ 的数字串 $s_1 s_2 \dots s_n$，其中 $s_i = 4 r_i + 2 y_i + b_i$，$r_i, y_i, b_i$ 分别表示第 $i$ 个位置上红色、黄色、蓝色棋子的个数。
>
> 数据范围：$1 \le n \le 2 \times 10^6$，$1 \le s_i \le 7$。

# T3

> 有 $n$ 个人站成一排，从左到右依次编号为 $1, 2, \dots, n$，每个人是村民或者狼人。村民总是说真话，狼人可能说真话，也可能说假话，并且狼人不可能站在相邻的位置上。第 $i$ 个人说的话用 $(d_i, b_i)$ 表示：如果 $d_i$ 为 L，那么他说他的左边（不包括他自己）有 $b_i$ 个狼人；如果 $d_i$ 为 R，那么他说他的右边（不包括他自己）有 $b_i$ 个狼人。对每组数据判断是否存在合法的身份分布：若存在，输出任意一种可能的方案，即一个长度为 $n$ 的 01 串，其中第 $i$ 位为 0 表示第 $i$ 个人是村民，为 1 表示是狼人；若信息互相矛盾，则输出 -1。
>
> 数据范围：$1 \le T \le 10^5$，$1 \le n \le 5 \times 10^5$，所有数据的 $n$ 之和不超过 $2 \times 10^6$，$0 \le b_i \le n$，$d_i$ 为 L、R 中的一个。

# T4

> 给定一个数组 $b_1, b_2, \dots, b_m$ 和一个数字 $k$，得分 $f(b, k)$ 的定义如下：初始时集合 $S$ 为空，依次对 $i = 1, 2, \dots, m$ 执行操作——先把 $b_i$ 插入集合 $S$，随后你可以选择执行至多一次如下操作：把 $\mathrm{mex}(S)$ 插入集合 $S$。在整个过程中，后一步操作至多执行 $k$ 次。数组的得分定义为处理完所有元素后 $\mathrm{mex}(S)$ 能达到的最大值，其中 $\mathrm{mex}(S)$ 表示不属于集合 $S$ 的最小非负整数。
>
> 给定一个数组 $a_1, a_2, \dots, a_n$ 和 $q$ 组询问，每组询问给出两个数 $m, k$，要求回答 $f([a_1, a_2, \dots, a_m], k)$，输出 $q$ 个询问的答案。
>
> 数据范围：$1 \le n, q \le 5 \times 10^5$，$1 \le k \le m \le n$，$0 \le a_i \le n$。
