# T1

> 蜗蜗为自己安排了 $n$ 个工作日，第 $i$ 个工作日的计划工作量为正整数 $a_i$。蜗蜗可以在任意两个工作日之间、所有工作日之前或之后插入任意多个休息日，休息日的计划工作量为 $0$，原有工作日的相对顺序和计划工作量保持不变。蜗蜗希望日程满足以下要求：对于任意一段至少包含一个工作日的连续日期，这段日期的平均计划工作量都不小于 $1$，完全由休息日组成的连续日期不受这一要求限制。请帮助蜗蜗求出最多可以插入多少个休息日。
>
> 数据范围：$1 \le n \le 10^5$，$1 \le a_i \le 10^9$。

# T2

> 一项顺序计算任务的总工作量为 $l$，从进度 $0$ 开始，按顺序完成后进度为 $l$。任务分为 $n$ 个阶段，第 $i$ 个阶段从进度 $a_{i-1}$ 开始，到进度 $a_i$ 结束，其中 $a_0=0$、$a_n=l$。在第 $i$ 个阶段，任意时刻的处理速率均不得超过每小时 $v_i$ 单位工作量；允许暂停计算，忽略切换阶段和调整处理速率所需的时间。日志中有 $m$ 条中间记录，第 $i$ 条记录表示任务开始 $t_i$ 小时后进度恰好到达 $x_i$，记录中的进度和时刻都严格递增；任务在时刻 $0$ 开始，并在时刻 $t_{end}$ 完成，这两条首尾记录始终可信、不能删除。对于进度递增的任意两条记录，如果它们的时间差严格小于按各阶段最高处理速率完成两处进度之间工作量所需的时间，就能确定这两条记录之间出现了超出速率限制的情况。蜗蜗可以删除一些中间记录，请问最少需要删除多少条中间记录，才能使包括首尾记录在内的任意两条未删除记录都不足以证明它们之间发生过超出速率限制的情况？如果无论删除多少条记录都无法满足要求，输出 $-1$。
>
> 数据范围：$1 \le T \le 10^4$，$1 \le n,m \le 2 \times 10^5$，$2 \le l,t_{end} \le 10^9$，$v_i \in \{5,10,15,20,25,30,40,50,60,70,80,90,100,110,120\}$，$0<x_1<x_2<\dots<x_m<l$，$0<t_1<t_2<\dots<t_m<t_{end}$，且 $\sum n \le 2 \times 10^5$，$\sum m \le 2 \times 10^5$。

# T3

> 灯阵共有 $n$ 盏灯，编号为 $1$ 到 $n$，每盏灯可以处于亮起或熄灭状态。第 $i$ 盏灯的控制器设有一个整数闭区间 $[l_i,r_i]$，它只统计其他 $n-1$ 盏灯中亮起的数量：如果这个数量在 $[l_i,r_i]$ 内，第 $i$ 盏灯应当亮起；否则它应当熄灭。如果一种亮灭配置中的所有灯都符合各自控制器的要求，就称这种配置为稳定配置。对于整数 $k$，若存在恰好有 $k$ 盏灯亮起的稳定配置，就将 $k$ 加入集合 $S$（同一个 $k$ 即使对应多种稳定配置也只计入一次）。蜗蜗给定了 $n$ 个整数 $d_1,d_2,\dots,d_n$，第 $i$ 个控制器的区间会从所有满足 $0 \le l_i \le r_i \le d_i$ 的整数闭区间中等概率选择，各个控制器的选择相互独立。请你求出随机选择所有区间后，集合 $S$ 的大小的期望，答案对 $998244353$ 取模（若该期望为 $P/Q$，输出 $P \cdot Q^{-1} \bmod 998244353$，其中 $Q^{-1}$ 表示 $Q$ 在模 $998244353$ 意义下的乘法逆元）。
>
> 数据范围：$1 \le n \le 500$，$0 \le d_i \le n-1$。

# T4

> 蜗蜗正在为一组数字信号配置频段编号。共有 $n$ 个信号，它们按顺序排列，第 $i$ 个信号的编号为 $p_i$，所有编号恰好组成 $1$ 到 $n$ 的一个排列。对于正整数 $k$，定义欧拉函数 $\varphi(k)$ 为不超过 $k$ 且与 $k$ 互质的正整数个数（例如 $\varphi(1)=1$，$\varphi(6)=2$）。蜗蜗用 $\varphi(p_i \times p_j)$ 作为两个不同信号的配对得分。现在有 $q$ 次询问，每次给定一个区间 $[l,r]$，请从区间内选出两个不同位置，求配对得分的最大值，即 $\max_{l \le i<j \le r}\varphi(p_i \times p_j)$。
>
> 数据范围：$2 \le n \le 5 \times 10^5$，$1 \le q \le 5 \times 10^5$，$p$ 是 $1$ 到 $n$ 的一个排列，每次询问满足 $1 \le l<r \le n$。
